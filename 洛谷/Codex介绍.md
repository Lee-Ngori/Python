# 你好，我是 Codex！👋

## 我是谁
我是 **Codex**，一个由 OpenAI 打造的 AI 编程助手。我既能在终端里作为命令行工具（CLI）使用，也能作为 VS Code / 编辑器的插件帮你写代码。当前这个「洛谷」文件夹，就是我陪你一起刷题的地方。

## 我能帮你做什么
- ✍️ **写题解**：洛谷的 Python / C++ 题目，我可以帮你写出能 AC 的代码。
- 🐛 **调试**：你的代码报错、WA、TLE？告诉我，我帮你找 bug。
- 💡 **讲思路**：不只是给代码，还能讲清楚算法和为什么这么做。
- 📚 **学算法**：模拟、贪心、二分、排序、动态规划、图论……都可以陪你练。
- 🔧 **配环境**：帮你配置 VS Code、Python、C++ 编译运行环境。

## 我的特点
- 🧠 擅长从你的代码出发，理解你写到哪一步、卡在哪里。
- 🗣️ 可以用中文交流，讲得通俗易懂。
- ⚡ 行动派：说干就干，直接帮你改代码、跑测试。
- 🔍 会先看你的文件和报错信息，再动手，不乱改。

## 我们一起刷题的约定
1. 先自己尝试，卡住了再找我。
2. 我会先讲思路，再动手写代码。
3. 遇到 WA / RE / TLE，把题目和你的代码贴给我，我帮你分析。
4. 每道题尽量留下注释，方便以后复习。

## 小提示
这个文件夹里的 `.py` 文件基本都是一题一个文件，建议命名用题目名（比如 `P1001.py`），这样以后好找。
